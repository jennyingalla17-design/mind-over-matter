# 🧠 Mind Over Matter

A student learning & wellness web app — built for senior high students.

## 🌟 Live Site
**https://jennyingalla17-design.github.io/mind-over-matter/**

## ✨ Features
- 🎮 **Game 01 — Word Quest**: upload any PDF/Word/TXT, AI generates questions (scramble, cloze, spell, match)
- 🔢 **Game 02 — Math & Science Quiz**: 80-question pool, up to 35 questions, fresh set every session
- 📚 **Study Lab**: 9 answerable study techniques (Active Recall, Flashcards, Pomodoro, Cornell Notes, Mind Map, Feynman, SQ3R, Blurting, Spaced Repetition) with PDF export
- 🧘 **Mind Care**: breathing exercise, 5-4-3-2-1 grounding, NCMH crisis hotline (1553)
- 📅 **Planner**: to-do list + Pomodoro timer
- 📔 **Journal**: notes saved locally
- 🏆 **Rewards**: XP, levels, unlockable affirmation stickers

## 🚀 Self-hosting
Just open `index.html` in any browser. All data saves locally via localStorage.
